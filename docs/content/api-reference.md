# API Reference

This project is a VS Code extension sample. The documentation here summarizes the available commands, settings, and contribution points.

## Commands

- `getting-started-sample.sayHello`
  - Displays the sample hello command.

- `getting-started-sample.runCommand`
  - Runs a sample action used by the walkthrough.

- `getting-started-sample.changeSetting`
  - Toggles a sample configuration value.

- `getting-started-sample.setContext`
  - Sets a sample context key used by follow-up walkthrough steps.

- `getting-started-sample.viewSources`
  - Opens the extension source files.

## Settings

- `getting-started-sample.sampleSetting`
  - Type: boolean
  - Description: A sample setting used to demonstrate extension configuration.

## Walkthrough contributions

The extension contributes a walkthrough under the `sample` ID. The walkthrough includes steps for:

- running commands,
- changing settings,
- setting and using context,
- installing other extensions,
- opening views,
- platform-specific content.
