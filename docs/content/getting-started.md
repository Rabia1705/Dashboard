# Getting Started

Welcome to the documentation site for the Getting Started Sample repository.

## Run the local preview

1. Install dependencies if needed:

   ```bash
   npm install
   ```

2. Start the docs server:

   ```bash
   npm run docs:serve
   ```

3. Open the browser at `http://localhost:8080`.

## What you can do here

- read the repository overview,
- inspect extension commands and walkthrough behavior,
- review contribution guidelines,
- learn the documentation standards used in this site.
