# Standard Documentation

This section describes the standards for documentation within this repository.

## Structure

- `docs/index.html` — static documentation UI.
- `docs/styles.css` — layout and styling.
- `docs/app.js` — navigation and markdown loading.
- `docs/content/` — markdown source pages.
- `scripts/serve-docs.js` — lightweight local server.

## Content guidelines

- Use plain Markdown for each document.
- Add one topic per file.
- Keep the first paragraph as a summary.
- Keep navigation titles consistent with the page purpose.

## Publishing

This static site is ready to be published from the `docs/` folder.

When hosted, the repository becomes a central documentation hub for this extension.
