# Power BI Style Dashboard

Open the interactive dashboard page:

- [Launch Dashboard](../dashboard.html)

## How To Use

1. Click **Choose Workbook** and select `Observations (1).xlsx` from your Downloads folder.
2. Select a worksheet if your file has multiple sheets.
3. Pick the fields for **Date**, **Category**, and **Metric**.
4. Review KPI cards and visualizations.

## Notes

- The dashboard runs entirely in your browser.
- No upload to external services is required.
- If your workbook changes, reload it and the visuals will refresh.
