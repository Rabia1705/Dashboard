# Contributing

This documentation repository is designed to be easy to extend.

## How to contribute

- Add new markdown pages in `docs/content/`.
- Add new entries to `docs/app.js` if you need more navigation items.
- Keep page titles consistent and descriptions short.
- Use clear headings and code blocks for configuration details.

## Recommended workflow

1. Create or update markdown files in `docs/content/`.
2. Edit `docs/app.js` to expose new pages in the navigation.
3. Preview the site locally with `npm run docs:serve`.
4. Commit documentation changes to source control.
